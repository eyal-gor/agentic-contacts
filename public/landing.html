Features

Everything a personal CRM needs. Nothing it doesn't.

Built for one person, or a small team, working with agents. One Worker, one database, one page.

API and CLI first

Every action is a plain REST call, and the CLI is a thin client over the same API. Anything that can make an HTTP request can use it.

No duplicates

Upsert matches on email, LinkedIn or domain. Shared names are only flagged. Merge previews first and keeps every email and conversation.

Knows who added what

Every contact and company records who created it: you, a system, or a named agent. Filter by source when an agent gets it wrong.

Follow-ups that surface

Log calls, emails and meetings. Set a next date and a reason. "Who's due this week" is one call, one view.

Pipeline, calendar, lists

Drag people through stages, see every touchpoint on a calendar, and group batches into lists. Works on your phone too.

Yours, on Cloudflare

Deploys as one Worker with a D1 database in your own account, small enough for Cloudflare's free tier. Contacts never leave it.

For agents

Safe for an agent to call a thousand times.

Agents repeat themselves. They rediscover the same person, misspell a name, or find a second email address. The API is built for that.

  • Upsert, not insert. Same email or LinkedIn means the same person, so the record is updated instead of copied. The name is never overwritten.
  • It says when it's unsure. If the input matches two different people, the call stops with a 409 and lists both, instead of guessing.
  • Dry runs for anything destructive. Merges preview exactly what will be kept, combined and moved before anything is written.

An agent adds someone it already knows

curl -X POST "$API/contacts?upsert=1" \
  -H "Authorization: Bearer $KEY" \
  -d '{"name":"J. Okafor",
       "emails":["james@harborlabs.dev"],
       "title":"CTO",
       "addedBy":"Prospect Hunter (agent)"}'

// 200: updated, not duplicated
{ "name": "James Okafor", "title": "CTO",
  "upsert": { "action": "updated",
    "matchedOn": [{ "kind": "email" }] } }

Or from the terminal

# contacts = npm run cli --
contacts log <id> -c call -s "Walked through the API" --next 2026-11-14
contacts due --window week
contacts dupes
contacts merge <id> <id>            # preview; add --yes to merge
Self-host

Up in about ten minutes.

You need Node 20+ and a Cloudflare account. There's no sign-up and nothing else to install.

Clone and install

git clone https://github.com/eyal-gor/agentic-contacts
cd agentic-contacts && npm install

Create your database

Put the id it prints into wrangler.toml under [[d1_databases]], then create the tables.

npx wrangler d1 create agentic-contacts
npm run migrate

Set your key and deploy

In wrangler.toml, remove the [[secrets_store_secrets]] block and the Google sign-in vars, which point at the author's account. Then set a key of your own and deploy.

npx wrangler secret put API_KEY
npm run deploy

Point your agents at it

Give them the Worker URL and the key. Use ?upsert=1 when creating contacts, and they'll keep the list clean.

export CONTACTS_API_URL=https://agentic-contacts.<you>.workers.dev
export API_KEY=…
npm run cli -- list
